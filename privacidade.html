Política de privacidade

Atualizada em 29 de outubro de 2026.

Quem usa

A Fábrica Cofre Aberto é usada apenas pelo dono do canal Cofre Aberto, para gerenciar o próprio canal. Não há outros usuários.

Quais dados acessa

Com a autorização do dono do canal, a ferramenta usa a API do YouTube para: ler o nome do canal, enviar vídeos como privados, definir a miniatura e organizar playlists. Ela não lê nem guarda dados de espectadores, comentários ou outras contas.

Como guarda

A autorização fica armazenada de forma criptografada no computador do dono do canal e no cofre de segredos do repositório privado usado para a produção. Nenhum dado é vendido, compartilhado ou enviado a terceiros.

Como revogar

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions.

O uso dos dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.
